# Temozonia Fonts

Las fuentes se cargan vía `next/font` directamente desde los CDNs de Google Fonts.
No se requieren archivos locales en esta carpeta.

Fuentes usadas:
- **Playfair Display** (Display)
- **Inter** (Body)
- **Cormorant Garamond** (Script)
- **Orbitron** (Accent)

Esto se configura en `src/app/[locale]/layout.tsx`.
